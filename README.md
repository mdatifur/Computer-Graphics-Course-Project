# Dhaka in Motion: Various Transport System Simulation

A Computer Graphics project developed using OpenGL and GLUT in C++.

## Features

- Railway Station Animation
- Metro Rail Simulation
- Airport Scene
- Traffic Light System
- Moving Vehicles
- Cloud Animation
- Keyboard Controls

## Technologies Used

- C++
- OpenGL
- GLUT

## Project Scenes

1. Railway Station
2. Metro Rail
3. Airport Simulation
4. Smart City Scene

# Controls & Instructions

## Project Navigation

| Key | Action                     |
| --- | -------------------------- |
| A   | Railway Station Scene      |
| K   | Metro Rail Scene           |
| J   | Airport Scene              |
| H   | City Scene                 |
| I   | Back to Instruction Screen |

---

# Team Contributions & Scene Controls

## 1. Quazi Saad — Metro Rail Scene

### Open Scene

Press `K`

### Controls

| Key / Action      | Function       |
| ----------------- | -------------- |
| Q                 | Increase Speed |
| S                 | Decrease Speed |
| Mouse Left Click  | Red Signal     |
| Mouse Right Click | Green Signal   |
| Y                 | Yellow Signal  |

---

## 2. Atifur Rahaman Shohan — Railway Station Scene

### Open Scene

Press `A`

### Controls

| Key / Action | Function              |
| ------------ | --------------------- |
| W            | Increase Train Speed  |
| S            | Decrease Train Speed  |
| Space        | Pause Animation       |
| R            | Reset Scene           |
| Mouse Click  | Change Railway Signal |

---

## 3. Zafrin Alam Tanha — Smart City Scene

### Open Scene

Press `H`

### Controls

| Key / Action      | Function                   |
| ----------------- | -------------------------- |
| G                 | Green Light (Cars Move)    |
| R                 | Red Light (Cars Stop)      |
| Left Mouse Click  | Increase Cloud Speed       |
| Right Mouse Click | Decrease Cloud Speed       |
| I                 | Back to Instruction Screen |

---

## 4. Fariha Tasnim — Airport Scene

### Open Scene

Press `J`

### Controls

| Key / Action | Function                   |
| ------------ | -------------------------- |
| Space        | Airplane Take Off          |
| P            | Pause / Resume             |
| I            | Back to Instruction Screen |
